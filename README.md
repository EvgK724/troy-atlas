# TROY — Троя в контексте

[Открыть приложение](https://evgk724.github.io/troy-atlas/)

Тёмный неоновый атлас о Трое с тренировкой памяти. Приложение связывает географию, археологические слои, хеттские документы, гомеровский эпос и историю раскопок, чтобы сведения запоминались через контекст. Крупный регулируемый текст, оригинальные схемы и карточки рассчитаны на телефон, планшет и большой экран.

## Что внутри

- **7 тем:** место, слои, Вилуса, война, эпос, люди и открытие.
- **10 связей между темами:** от положения у пролива к культурным контактам, от слоя находки к её датировке, от эпической версии к археологическому вопросу.
- **34 карточки:** сначала самостоятельное воспроизведение, затем открытие ответа, объяснение связи и возвращение к исходной теме.
- **3 оригинальные схемы:** укреплённая цитадель, последовательность слоёв I–IX и связь Эгейского моря с Мраморным через Дарданеллы.
- Оригинальная иконка, QR-код для открытия сайта, автономный HTML и проверка обновлений.

В тренировке нет обязательного количества заданий или экзаменационной оценки. После открытого ответа пользователь сам выбирает, когда вернуться к карточке. «Ещё раз» назначает возвращение через 10 минут; успешное воспроизведение постепенно увеличивает интервал: 1, 3, 7, 14 и 30 дней. Сведения о повторениях создаются только после действия пользователя.

## Источники и границы интерпретации

Учебные материалы находятся в [`content.json`](content.json), библиография с указанием того, что подтверждает каждый источник, — в [`sources.json`](sources.json). Использованы материалы UNESCO, музеев, исследовательских университетов и тексты античной традиции. Источник литературного сюжета и источник археологического утверждения различаются.

Археологический памятник на Гиссарлыке установлен, но это не делает каждое событие эпоса доказанным. Отождествление Вилусы с Троей рассматривается как научная интерпретация; обстоятельства разрушений, возможный исторический фон войны и связь отдельных персонажей с реальными людьми требуют самостоятельных оговорок. «Илиада» не является отчётом о раскопках и не рассказывает всю войну от начала до падения города. Даты и периодизация в приложении даны с точностью, подходящей для вводного курса.

Все иллюстрации созданы из SVG-геометрии специально для TROY. Они помогают понять отношения между объектами, но не подменяют обмеры:

- **Цитадель:** условные здания, план и пропорции; это не точная реконструкция конкретного слоя Трои.
- **Слои:** I–IX — крупные учебные периоды с внутренними подразделениями. Равная толщина полос не означает равную длительность или измеренную глубину.
- **География:** берега и расстояния условны. Схема показывает связи морей и положение Трои, а не реконструкцию береговой линии бронзового века. Стрелка не означает течение или доказанную монополию на судоходство.

Описание происхождения и ограничений графики: [`docs/assets/provenance.json`](docs/assets/provenance.json). Внешние фотографии и копии музейных изображений в графику не включены.

## Данные и работа без сервера

Приложение статическое: собственный сервер, учётная запись и база данных не требуются. Прогресс повторения и настройки сохраняются в `localStorage` текущего браузера. Они не синхронизируются между устройствами; очистка данных сайта удаляет локальные записи. Автономная копия, открытая как файл, может иметь отдельное хранилище в зависимости от браузера.

Файл `TROY.html` содержит интерфейс, учебный материал и графику. Его можно сохранить и открыть без подключения к сети. Внешние страницы источников и получение новых версий требуют интернета. Установка ярлыка сайта на домашний экран сама по себе не заменяет сохранённую автономную копию.

## Сборка

Основная сборка использует Python 3 и стандартную библиотеку. Команды выполняются из корня репозитория:

```sh
python3 scripts/build.py --export ../../outputs
```

Сборка создаёт страницу для публикации в `docs/`, автономный `TROY.html` и файл версии. Аргумент `--export` задаёт каталог для пользовательской автономной копии; `../../outputs` соответствует структуре рабочего каталога, в которой создан проект. При размещении проекта в другом месте можно указать собственный путь.

Готовые QR-код и иконки хранятся в репозитории. Перегенерация QR-кода отдельно требует **ReportLab** и **Pillow**:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install reportlab pillow
.venv/bin/python scripts/qr.py
```

QR-код ведёт на `https://evgk724.github.io/troy-atlas/`. После изменения активов следует повторить сборку, чтобы обновить идентификатор выпуска.

Для локального просмотра:

```sh
python3 -m http.server 8770 --directory docs
```

Откройте `http://localhost:8770/`. Для проверки логики расписания повторений:

```sh
node tests/learning.cjs
```

Проверки браузерных сценариев (нужны Playwright и установленные Chromium/WebKit):

```sh
node tests/browser.cjs
```

Параметры: `BASE_URL`, `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE` и `QA_OUTPUT`.

## Публикация и обновления

GitHub Pages публикует каталог `docs/` ветки `main`. Адрес приложения: [evgk724.github.io/troy-atlas](https://evgk724.github.io/troy-atlas/).

Онлайн-версия проверяет `version.json` при открытии, возвращении в приложение и периодически, пока страница открыта. Идентификатор выпуска зависит от содержимого. Обновление откладывается во время активного повторения и при несохранённом прогрессе. Настройка автообновления и ручная проверка доступны в окне информации о приложении. Автономный файл не получает изменения автоматически — для него нужно сохранить новый выпуск.

Манифест [`docs/site.webmanifest`](docs/site.webmanifest) использует относительные `start_url` и `scope`, режим `standalone` и иконки 192×192 и 512×512. Значимые элементы эмблемы находятся в центральной безопасной зоне для маскируемых иконок.

## Структура

| Путь | Назначение |
|---|---|
| `src/` | Разметка, оформление, интерфейс, повторение и обновления |
| `content.json` | Темы, связи, хронология, люди и карточки |
| `sources.json` | Библиография и основания утверждений |
| `docs/assets/` | SVG, иконки, QR-код и происхождение иллюстраций |
| `scripts/` | Сборка, версия, вспомогательная генерация активов |
| `tests/` | Проверки логики обучения |
| `docs/index.html` | Страница GitHub Pages |
| `docs/TROY.html` | Автономная копия |
